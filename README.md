# Student Performance Analysis using Data Cleaning & Visualization

## Overview
This project focuses on analyzing student performance data using Python. The dataset was cleaned, processed, and visualized to identify factors affecting student exam scores.

## Objectives
- Handle missing values
- Perform data preprocessing
- Create meaningful visualizations
- Generate insights from data

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset Features
The dataset contains factors such as:
- Hours Studied
- Attendance
- Sleep Hours
- Motivation Level
- Internet Access
- Teacher Quality
- Family Income
- Exam Score

## Data Cleaning Process
- Checked missing values
- Filled missing categorical values using mode
- Verified dataset structure
- Removed inconsistencies

## Visualizations Created
- Correlation Heatmap
- Attendance Distribution
- Motivation Level Analysis
- Study Hours vs Exam Score
- Internet Access vs Exam Score

## Key Insights
- Higher study hours improve exam scores
- Attendance positively impacts performance
- Motivation level affects academic success
- Internet access contributes to better outcomes

## Project Outcome
This project helped in understanding:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Storytelling using data
