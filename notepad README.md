# Student Performance Analysis using Data Cleaning & Visualization

## Project Overview

This project analyzes student performance data using Python libraries such as Pandas, Matplotlib, and Seaborn.

## Features

- Data Cleaning
- Missing Value Handling
- Exploratory Data Analysis (EDA)
- Data Visualization
- Correlation Analysis

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset

StudentPerformanceFactors.csv

## Key Insights

- Study hours positively affect exam scores.
- Attendance impacts academic performance.
- Internet access contributes to better results.
- Motivation level influences student outcomes.
